# SDG 지역 상황판 (Palantir식 지역×목표 매트릭스 허브) — 설계 명세

**작성일**: 2026-06-11
**상태**: 설계 확정 (구현 계획 대기)
**프로젝트**: budget.ai.kr (마을살림/나라살림)

---

## 1. 목적 (Why)

UN SDGs(17 목표 → 169 세부목표 → 지표)의 **전문성·과학성·체계성**을 한국 지역(광역/기초) 단위 공개데이터·예산에 적용하여, **누구나 쉽게 지역별 지속가능발전 상황을 확인**할 수 있는 팔란티어식 상황판을 만든다.

핵심 원칙(CLAUDE.md 준수):
- **데이터 날조 금지** — 검증된 실데이터만 점수화, 없으면 정직하게 '데이터 준비중'.
- UN 169 세부목표 **체계는 데이터 유무와 무관하게 항상 노출** → 전문성·체계성 확보.
- 정치 중립 / 출처 명시 / 지표를 곧 SDG 달성도로 단정하지 않음(기존 /sdg 고지 계승).

## 5. 정규화 방법 (과학성)

각 (지역, 목표) 셀:
1. 목표에 매핑된 대표 지표 선택(indicator-map).
2. 16 광역 값 분포에서 **min-max 정규화 → 0~100**.
3. 방향 반영: `higherBetter=false`면 `100 - score`.
4. 해당 지표가 없으면 셀 = `null`(준비중, 빗금 표시).
5. 툴팁/패널에 **원값·단위·연도·출처·전국 순위** 항상 노출(정규화 점수만 단독 노출 금지).

> 종합 'SDG 점수'로 단정하지 않음 — 셀은 "대표 지표 정규화값"임을 UI에 명시(기존 /sdg 고지 계승).

## 10. 예산 효율성·코멘트 상세 (D6/D7)

### 10.1 예산-성과 효율 사분면 (budget-efficiency.ts)
- X축 = 1인당 세출(또는 예산규모), Y축 = 해당 지역 **SDG 대표지표 종합 정규화 평균**(데이터 보유 목표만).
- 4사분면: `저예산·고성과=효율형` / `고예산·고성과=적극투자형` / `저예산·저성과=여력부족` / `고예산·저성과=점검필요`.
- **면책 필수**: "예산 투입 대비 대표지표 성과의 **상관**이며, 인과·목표별 세부배분을 의미하지 않음. 지역 여건(인구구조·면적) 차이 존재."
- 점수/매트릭스에 **혼입 금지** — 별도 관점 패널.

### 10.2 규칙형 예산 편성 코멘트 (budget-comment.ts)
- 입력: 재정자립도·자주도·지방채무비율·1인당 세출·의존재원 비율(fiscal-health-data 실데이터).
- 로직: 각 지표를 **전국 평균/유사 인구규모 그룹**과 비교 → 임계값 기반 결정론 문장 조립(`Math.random` 금지, 동일 입력=동일 출력).
- 예: "재정자립도 28%는 전국평균(45%) 하회 → 의존재원 비중 높아 자체 SDG 재원 확보 취약. 지방채무비율 X% 주의/양호."
- **AI 보강(옵션, Phase 3)**: 동일 입력을 기존 Gemini 파이프라인(`checkGeminiRateLimit`+캐시+면책)에 넘겨 서술 보강. AI 실패 시 규칙형으로 **graceful fallback**.

## 11. 비범위 (YAGNI)
- **SDG 목표별 예산 배분 추정**(한국 세출 미분류 → 날조 금지 → 영구 제외). 효율은 '총예산 대비 성과 상관'으로만.
- 외부 SDSN 지수 연동(라이선스·갱신 부담 → 제외).
- 시계열 트렌드(초기 단일연도 → 후속).
- 추정/합성 데이터로 빈 셀 채우기(날조 금지 → 영구 제외).
- 효율 사분면을 '우열/평가'로 단정(여건 차이 → 면책 후 관점 제공만).
