# SDG 상황판 가독성 재설계 (A: 스코프 선택 + 단일대상 드릴다운) — 설계 명세

**작성일**: 2026-06-11
**상태**: 설계 확정 (구현 대기)
**선행**: Phase 1 매트릭스(`2026-06-11-sdg-situation-board-design.md`) — lib 재사용
**순서**: A(본 문서) → B(온톨로지 다이어그램) → C(인터랙티브 what-if/최적값)

---

## 1. 문제 / 목적
Phase 1의 16×17 매트릭스가 한 화면에 전부 떠서 **가독성이 낮다**(사용자 피드백 "너무 복잡"). 해결: **스코프 먼저 선택 → 한 대상만 깔끔히** 보여주는 드릴다운 구조. 밀집 매트릭스는 선택적 '전체 비교' 탭으로 격하.

## 2. 핵심 결정 (확정)
| # | 결정 | 값 |
|---|------|----|
| D1 | 1차 네비 | **스코프 선택**(전국/광역/기초) 세그먼트 |
| D2 | 기본 화면 | **단일 대상 집중 + 드릴다운** (한 화면에 한 대상의 17 SDG) |
| D3 | 첫 화면 | **전국 종합** |
| D4 | 전국값 | goal별 16광역 실값의 **인구 가중 평균(절대값)** + 데이터 보유 목표 수 고지 |
| D5 | 기초 데이터 | **실데이터만**(진학률 Goal4 226시군구 + 재정 맥락), 나머지 목표 '데이터 준비중' (날조 금지) |
| D6 | 매트릭스 | 기존 16×17은 **'전체 비교' 접이식 탭**으로 격하(파워유저용) |

## 3. 화면 구조
```
┌──────────────────────────────────────────────┐
│  [ 전국 ] [ 광역 ] [ 기초 ]   스코프 세그먼트       │
│  (광역/기초 시) ▼ 지역 드롭다운                   │
├──────────────────────────────────────────────┤
│  단일 대상의 17 SDG 화면                          │
│  · 전국 → 전국 종합(17목표 카드, 전국 평균값) +     │
│          강점/약점 + "N개 목표 데이터 보유" 고지     │
│  · 광역 → 한 광역 프로파일(17목표 게이지 + 전국 순위 │
│          + 💰재정 맥락 + 강점/약점 Top3)           │
│  · 기초 → 시군구 프로파일(진학률+재정 실측,         │
│          나머지 '준비중')                         │
│  [ 전체 비교 ▸ ] 16×17 매트릭스(접힘, opt-in)      │
└──────────────────────────────────────────────┘
```

## 5. 데이터
- **재사용(Phase 1)**: `region-normalize`, `indicator-map`, `matrix`, `board-data` 그대로.
- **신규 `src/lib/sdg/national.ts`** — `nationalAggregate()`: goal별 16광역 실값의 인구 가중 평균(절대값) + 데이터 보유 목표 집합. (정규화 아님 — 전국 '수준'을 절대값으로)
- **신규 `src/lib/sdg/municipal.ts`** — `getMunicipalSDG(sido, sgg)`: `public/data/admission-sgg-2025.json`(진학률 226 실측) + `fiscal-health-data`의 시군구 재정. 반환 = `{ goal4Admission, fiscal, availableGoals: [4], note }`. 합성 데이터 미사용.
- **광역 순위**: 기존 매트릭스에서 16광역 중 순위 계산(`matrix.ts`에 `goalRanking(matrix, goal)` 추가 또는 컴포넌트 내 계산).

## 6. 광역/시군구 목록 출처
- 16광역: `CANON_16`(region-normalize).
- 시군구: `fiscal-health-data`의 기초 목록(`getAllDistrictFiscalData()`) 또는 `admission-sgg-2025.json`의 (sido,sgg) — 광역별 필터링. 광주전남 선택 시 광주+전남 시군구 합쳐 표기.

## 7. 라우팅
- 기존 `/sdg` 유지. `SDGBoard`를 스코프 구동으로 교체. 첫 진입 = 전국 종합.

## 8. 검증
- jest: `national.ts`(인구가중 평균·데이터보유 집합), `municipal.ts`(실데이터 매핑·공백) TDD.
- 컴포넌트: tsc + next build + 브라우저 프리뷰(스코프 전환·드릴·매트릭스 접힘, 콘솔 0).
- 정직성: 기초에 합성 SDG 점수 미노출(진학률·재정만), 모든 뷰에 "대표지표·종합달성도 아님" 고지.

## 9. 비범위 (YAGNI / 후속)
- 온톨로지 다이어그램 → B.
- 인터랙티브 what-if/최적값 → C.
- 기초 SDG 전체 목표 실데이터(KOSIS 시군구 수집) → 별도(데이터 가용성 의존).
- 합성/추정값으로 기초 빈 목표 채우기 → 영구 제외(날조 금지).
