## 3. 구현 방식 (라우트 그룹 이동)
- `src/app/(ai-society)/layout.tsx` 신규 — 좌 사이드바 + `{children}` 콘텐츠 슬롯.
- 위 11개 `src/app/<route>/` 폴더를 **`src/app/(ai-society)/<route>/`로 이동**.
  - 라우트 그룹 `()`는 URL에 미반영 → `/simulator` 등 주소 **불변**.
  - 모든 import가 `@/` 절대경로 → 이동해도 안전.
  - `/sdg` 이동 시 하위 `/sdg/ontology`도 함께 이동(URL 불변).
- `src/components/layout/AISocietySidebar.tsx` 신규 — 11 도구를 그룹(시뮬레이션·분석/진단·도메인)으로 묶어 표시, `usePathname()`로 현재 활성 표시, next/link 클라 내비.
- 루트 `layout.tsx`(헤더)는 그대로 → 페이지 = 헤더 + 허브 사이드바 + 콘텐츠(중첩 레이아웃).

## 4. 사이드바 그룹핑
- **시뮬레이션**: AI기본사회·자치구AI·산업시뮬
- **분석/진단**: AI정책진단·재정혁신·AI효율화
- **도메인**: 공공은행·AI기본법·교육청예산·목표추적·SDG 상황판
(순서·그룹은 가독성 위주, 라벨은 기존 유지)

## 5. 헤더 연동
- 헤더 'AI기본사회' 드롭다운 유지(기존 11 링크) + **드롭다운 상단에 '🏛 AI기본사회 허브' 진입점**(/simulator 또는 대표 라우트)을 추가하거나, 드롭다운 라벨 클릭 시 허브 첫 도구로.
- 사이드바가 있으므로 드롭다운은 빠른 점프용으로 유지.

## 6. 반응형
- 데스크탑: 좌 사이드바 고정 + 콘텐츠.
- 모바일: 사이드바를 상단 접이식/드로어로(콘텐츠 폭 확보). 기존 모바일 헤더와 충돌 없게.

## 7. 검증
- `npx tsc --noEmit` EXIT 0, `npx next build` 성공 — **빌드가 11개 라우트 정상 생성 확인**.
- 브라우저: 11개 라우트 각각 200 + 사이드바 표시 + 활성 표시 + 도구 콘텐츠 정상. 사이드바에서 다른 도구 클릭 → 콘텐츠 교체(사이드바 유지). 콘솔 0.
- 회귀: 기존 헤더 링크·딥링크(/sdg/ontology 등) 모두 동작. 기존 jest 그대로 통과.
