## 1. AI 정책진단 시뮬레이션

### Context (맥락)
- 한국 지방자치단체 243개, 각각 다른 재정 상황
- 시민이 정책의 재정 영향을 이해하기 어려움
- 국회 법률안/조례가 내 지역에 미치는 영향을 알 방법이 없음
- 기존 비용추계는 전문가만 접근 가능 (NABO, KDI 보고서)

### Problem (문제)
1. 시민이 "공공병원을 세우면 우리 지역 재정에 어떤 영향이 있을까?" 같은 질문에 답을 얻을 수 없음
2. 정책 시뮬레이션 결과가 비과학적 (근거 없는 수치)
3. Gemini API 무료 티어 한계로 서비스 안정성 부족
4. 복합 정책(블록체인 + 공공은행) 시뮬레이션 불가

### Solution (해결책)
1. **표준단가 모듈** (`standard-costs.ts`): NABO/KDI 기준 12개 정책 카테고리별 과학적 비용추계
2. **3-관점 분석**: 재정(fiscal) + 주민(resident) + 정치(political) 다각도 분석
3. **Gemini 429 재시도**: 최대 3회 재시도 (5/7/9초) + 규칙 기반 fallback
4. **복합정책 감지**: `detectMultipleCategories()` + 시너지 할인 15%
5. **벤치마크 출처**: 독일 슈파카세, 경기도 지역화폐 등 실사례 자동 연결

## 2. 국회 법률안 + 지자체 조례 검색

### Context
- 22대 국회 법률안 16,000건+ 발의
- 전국 지자체 조례 수만 건
- 시민이 관련 법안/조례를 찾기 어려움

### Problem
1. 법률안 정식 명칭을 모르면 검색 불가 ("AI기본법" ≠ "인공지능 발전과 신뢰 기반 조성 등에 관한 기본법")
2. 법률안이 내 지역에 미치는 영향을 알 수 없음
3. 조례는 별도 사이트(elis.go.kr)에서만 검색 가능

### Solution
1. **NABO API 연동** (`/api/nabo/bills`): 열린국회정보 API로 법률안 검색
2. **법령정보 API 연동** (`/api/ordinance/search`): 국가법령정보센터 조례 검색
3. **선택 → 시뮬레이션 연결**: 법률안/조례 클릭 시 정책 입력란에 자동 입력
4. **5분 캐시**: 동일 검색어 반복 시 API 호출 절감

## 3. 글로벌 벤치마킹 & AI 정책 추천

### Context
- 전 세계 도시들의 재정 혁신 사례가 풍부
- 한국 지자체와 유사한 규모/재정 상황의 외국 도시 참고 가능
- 시민이 "우리 지역에 맞는 정책이 뭔지" 모름

### Problem
1. 어떤 외국 도시가 우리 지역과 유사한지 모름
2. 재정자립도별 맞춤 정책 추천이 없음
3. 벤치마크 도시의 성공 정책을 우리 지역에 어떻게 적용할지 모름

### Solution
1. **9개 글로벌 벤치마크 도시**: 인구/재정 유사도 점수로 매칭
2. **재정자립도 기반 추천**: <30% / 30-50% / 50%+ 구간별 맞춤 정책
3. **최적 정책 탐색 API** (`/api/chat/diagnosis/optimize`): 11개 카테고리 자동 평가

## 4. 정책 AI 어드바이저

### Context
- 시민이 정책에 대해 자유롭게 질문하고 싶음
- Gemini API 한도 제한으로 항상 AI 응답 불가
- "노란봉투법"처럼 정식 명칭이 아닌 통칭 사용

### Problem
1. API 한도 초과 시 "서비스 바쁨" 메시지만 표시
2. 질문형 입력("최고의 정책은?")에 비용추계로 잘못 응답
3. 법안 통칭 인식 불가

### Solution
1. **6개 주제별 fallback 규칙**: 공공은행, 지역화폐, 의료, 재정, 노동, 추천
2. **10분 응답 캐시**: 동일 질문 반복 시 즉시 응답
3. **질문형 감지**: 시뮬레이션에서 질문형 입력 시 Gemini에 정책 추천 지시
4. **법안 별명 매핑**: "노란봉투법" → 노동조합법 개정안

## 5. PDF/CSV/JSON 다운로드

### Context
- 시뮬레이션 결과를 보고서로 공유/보관 필요
- 지방의회, 주민설명회 등에서 활용

### Problem
1. `html2canvas`가 Tailwind v4 `lab()` 색상 함수 미지원 → PDF 생성 실패
2. 다크 테마가 인쇄 시 잉크 낭비

### Solution
1. **window.print() 방식**: 새 창에 인쇄용 HTML 생성 → 브라우저 인쇄 대화상자
2. **다크→라이트 자동 변환**: 인쇄 시 흰 배경, 검은 글씨
3. **CSV/JSON**: 클라이언트 사이드 Blob 생성, BOM 포함 (엑셀 한글 호환)

## 6. 모바일 UX

### Context
- 모바일 사용자 비중 높음
- 헤더 메뉴 항목 10개+ → 가로 스크롤 필요

### Problem
1. 모바일에서 "AI기본사회" 메뉴 보려면 헤더를 옆으로 스크롤
2. AI기본사회 하위 메뉴가 모바일에서 안 나옴

### Solution
1. **햄버거 메뉴**: 모바일에서 ☰ 버튼 → 풀스크린 메뉴
2. **계층 구조**: AI기본사회 하위 항목 들여쓰기 표시
3. **데스크탑 사이드바**: 페이지 내 섹션 앵커 이동
