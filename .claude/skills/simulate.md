# 시뮬레이션 비용추계 검증

다음을 실행하여 비용추계가 NABO 기준 범위 내인지 확인하세요:

1. **테스트 실행**: `npx jest src/lib/data/__tests__/standard-costs.test.ts --verbose --no-cache`
2. **결과 분석**: 97개 테스트 전체 통과 확인
3. **범위 검증 항목**:
   - 공공병원: 초기비용 400-1,200억원
   - 공공은행: 초기비용 300-1,000억원
   - 지역화폐/블록체인: 초기비용 30-500억원
   - 도로/인프라: 초기비용 300-5,000억원
   - 복합정책 시너지 할인: 정확히 15%
   - 운영비: 초기비용의 3-35%
4. **카테고리 감지 확인**: 주요 키워드가 올바른 카테고리로 분류되는지 확인
5. **결과 보고**: 통과/실패 항목을 테이블로 보고

실패 항목이 있으면 standard-costs.ts의 해당 카테고리 파라미터를 수정합니다.
